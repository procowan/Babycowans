# Babycowans Protocol V1.0.0 API Specification

This specification describes the currently implemented public developer API. It intentionally excludes proposed or historical interfaces absent from the current SDK and IDL.

## 1. Source-of-truth hierarchy

1. On-chain Rust program.
2. Generated protocol IDL.
3. `@babycowans/core-sdk` tracked source and package exports.
4. Current repository protocol/SDK/API documentation.
5. This specification.

## 8. Current protocol capability map

- Application registry and canonical ecosystem selection
- Application metadata configuration
- Application asset configuration
- Application-scoped roles
- Application payment policy and payment processing
- Membership lifecycle and NFT membership verification
- Reward create/claim/cancel lifecycle
- Direct token gating
- Composable gate policies
- Structured audit logs
- Event decoding
- Typed read API
- Transaction and application-bootstrap composition
- SPL Token / Token-2022 compatibility

## 9. Explicitly absent historical interfaces

- No `RewardCampaign` account or RewardCampaign API.
- No `create_reward_campaign` instruction.
- No `update_reward_campaign` instruction.
- No `createRewardCampaign()` method.
- No `updateRewardCampaign()` method.
- No `getRewardCampaign()` method.
- No `listRewardCampaigns()` method.
- No `update_asset_status` instruction.
- No `create_gate_policy` instruction.
- No `update_gate_policy` instruction.
- No `BabycowansClient` primary client class; the implemented high-level client is `BabycowansSDK`.

## 10. Error boundary

The generated IDL currently exposes **48 custom protocol errors**. Integrations should decode current IDL/SDK errors rather than depending on historical specification-only names.

## 11. Canonical ecosystem boundary

Ecosystem full name, ticker, token address, and mission are defined by repository canonical ecosystem constants. Applications must not substitute arbitrary token identity metadata for canonical protocol identity.

## 12. Compatibility and signing

- Solana RPC is an explicit external dependency.
- Wallet/private-key custody is not a Babycowans SDK responsibility.
- Token operations validate the expected SPL Token or Token-2022 program contract.
- bigint/PublicKey fidelity must be preserved across client boundaries.

## 13. Public API stability

A symbol is part of the current Babycowans Protocol V1.0.0 API only when it is implemented by the current program/IDL/SDK surface. Specifications must not advertise proposed or removed interfaces as current functionality.
