# Babycowans Protocol Support

This document defines the supported GitHub routes for help with Babycowans Protocol V1.0.0 and `@babycowans/core-sdk`.

## Bugs and reproducible defects

Use the repository's **Bug report** Issue Form for reproducible defects affecting the protocol, SDK, documentation, examples, local validator workflow, CI, or repository tooling.

Before filing, check the current repository state and include the smallest useful reproduction and non-secret evidence.

## Compatible improvement requests

Use the repository's **Feature request** Issue Form for compatible improvements to Babycowans Protocol V1.0.0 or its developer experience.

Requests must remain consistent with the current canonical protocol and release contract.

## Security vulnerabilities

Do **not** report an unremediated security vulnerability in a public Issue, pull request, or other public repository surface.

Follow [SECURITY.md](SECURITY.md) and use GitHub Private Vulnerability Reporting when available.

## Documentation and integration help

For non-security questions about documented integration behavior, first consult:

- [README.md](README.md)
- [docs/PROTOCOL.md](docs/PROTOCOL.md)
- [docs/API.md](docs/API.md)
- [docs/SDK.md](docs/SDK.md)
- [docs/COOKBOOK.md](docs/COOKBOOK.md)
- [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)

If the documentation appears incomplete or incorrect, use the Bug report Issue Form and identify the affected documentation surface.

## No private support channel or SLA

Babycowans does not declare a private support email, external support channel, response-time guarantee, or service-level agreement in this repository.

Do not send private keys, seed phrases, credentials, access tokens, or other secrets through any public support route.
